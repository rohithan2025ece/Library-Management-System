# Library Management System

A console-based Library Management System developed using C++. This project helps manage books and members, process book issues and returns, and search for books efficiently.

## Features

- **Book Management:** Add and view book details.
- **Member Management:** Add and view library member details.
- **Issue Books:** Issue available books to registered members.
- **Return Books:** Process book returns and update availability.
- **Search Books:** Search for books by title or author.
- **File Handling:** Store book and member records in files to retain data between program runs.

## Technologies Used

- C++
- Object-Oriented Programming
- Classes and Objects
- File Handling
- Standard Template Library (STL)

## How to Run

1. Install a C++ compiler such as GCC.
2. Open a terminal in the project folder.
3. Compile the source code:

   ```bash
   g++ LibraryManagement.cpp -o LibraryManagement
   ```

4. Run the program:

   **Windows:**
   ```powershell
   .\LibraryManagement.exe
   ```

   **Linux/macOS:**
   ```bash
   ./LibraryManagement
   ```

## Project Structure

- `LibraryManagement.cpp` — Main C++ source code.
- `README.md` — Project documentation.
- `books.txt` — Book records generated by the program.
- `members.txt` — Member records generated by the program.

## Purpose

This project demonstrates the practical use of C++ classes, file handling, and menu-driven programming to manage basic library operations.
